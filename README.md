# Digimon Story: Cyber Sleuth / Hacker's Memory — Modding Guide (AI-driven)

A working reference for modding **Digimon Story Cyber Sleuth: Complete Edition** (DSCS —
the PC/Steam release that contains *both* Cyber Sleuth and Hacker's Memory), written to be
read and acted on by Claude Code as much as by a human.

Read this file first. It says where everything is and which file answers which question,
so you don't have to load the whole guide into context.

This is the sibling of the Time Stranger guide (`../dsts-modding/`). Both games run on
Media.Vision's engine and share the MDB1 archive format, the `.mbe` table format and the
`.name/.skel/.geom/.anim` model split — but **the mod pipelines are completely different**
(Reloaded II + DSTS Mod Loader there, SimpleDSCSModManager here). See
[reference/vs-time-stranger.md](reference/vs-time-stranger.md) before reusing anything.

---

## Rules for the agent

1. **Never edit files inside the Steam install by hand.** Mods are built by
   SimpleDSCSModManager (SDMM) from a mod folder; SDMM re-packs `DSDBP.steam.mvgl`.
   Editing `resources/` or `DSDB/` directly gets overwritten and breaks Steam validation.
2. **The unpacked `DSDB/` folder is the read-only reference extraction.** Query it, diff
   against it, never write into it.
3. **Never open a game CSV in Microsoft Excel.** It rewrites quoting and silently corrupts
   the file. Use a text editor, or read/write programmatically.
4. **A mod CSV is a *patch*, not a copy.** Include only the rows you change. An empty cell
   is transparent (keeps the vanilla value) under the default `mberecord_merge` rule. Do
   not paste a whole vanilla table into a mod.
5. **The two ID forms are not interchangeable.** `digimon_common_para` uses the bare ID
   (`9`); `text/charname` and model filenames use the 4ID form (`1009`, `chr009`). Mixing
   them is the most common silent failure. See [guide/04-data-tables.md](guide/04-data-tables.md).
6. **Use softcodes for anything new.** Hardcoding a fresh ID makes your mod conflict with
   every other mod that picked the same number. See [guide/05-sdmm-mods.md](guide/05-sdmm-mods.md).
7. **Verify before you claim.** `python tools/cshm.py` proves what a table actually
   contains. Do not report a change as working until SDMM has built it and the user has
   confirmed in game.
8. **Back up the save first** before installing anything that adds records.
9. Facts marked `UNVERIFIED` are community claims or inference, not ground truth. See
   [guide/09-open-questions.md](guide/09-open-questions.md).

## The one command to run before theorising

```bash
python tools/cshm.py env
```

It prints the resolved game path, the unpacked database, how many tables each folder holds
and which mods are installed. If that fails, nothing else in this guide will work.
